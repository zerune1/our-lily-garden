# 🌸 Our Lily Garden — Mobile Edition

A pure HTML, CSS, and JavaScript version of Our Lily Garden — no Node.js,
no npm, no build step, no desktop software required. Built and hosted
entirely from an iPhone using Safari, GitHub, and Supabase (all free).

## What's included (Phase 1)

- Animated landing page (floating lilies, stars, fireflies, cats)
- Login/signup for two accounts, via Supabase Auth
- Garden dashboard that visually grows as notes are added
- Daily Love Notes: sticky/lily/cat styles, pin, favorite, live sync
  between both partners, plus an auto-rotating daily note
- Full database schema with security rules so only the two accounts
  can ever access the data
